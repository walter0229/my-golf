# 골프 스코어 관리

필드와 스크린골프를 따로 관리하고, 홀마다 사용한 클럽과 퍼팅 수를 기록하며,
내 클럽 거리를 기준으로 홀별 공략법을 계산해 주는 오프라인 웹앱(PWA)입니다.

설치 프로그램도, 서버도, 로그인도 필요 없습니다. 브라우저만 있으면 됩니다.

---

## 1. 무엇을 할 수 있나

| 기능 | 설명 |
|---|---|
| 필드 / 스크린 분리 | 라운드마다 구분해서 저장하고, 통계도 따로 볼 수 있습니다 |
| 골프장 · 코스 선택 | 베트남 필드 골프장 49곳 + 스크린 코스 템플릿 11개가 기본 내장. 18홀 코스는 하나만, 9홀 코스(OUT/IN, A/B/C…)는 두 개를 골라 18홀을 구성합니다 |
| 홀별 클럽 기록 | 클럽 버튼을 누르면 1회(초록) → 2회(파랑) → 해제로 돌고, 누르는 즉시 스코어가 계산됩니다 |
| 아이언샷 기록 | 남은 거리 · 샷 지점(페어웨이/러프/벙커) · 사용 클럽 · 결과(온그린/좌우 미스/짧음/오버, 2개까지)를 기록합니다 |
| 라운드 정보 | 날씨를 버튼으로 고르고, 동반자는 1. 2. 3. 칸에 한 명씩 따로 기록합니다 |
| 동반자별 통계 | 누구와 칠 때 스코어가 좋은지 이름 단위로 집계합니다 |
| 퍼팅 별도 관리 | 홀마다 퍼팅 수를 따로 기록해 라운드당 퍼팅 수, 3퍼트·1퍼트 횟수를 집계합니다 |
| 홀별 공략법 | 홀 거리와 내 클럽 거리를 비교해 "드라이버 → 남은 130m는 7번 아이언" 식으로 루트를 계산. 파5는 레이업 지점까지 잡아 줍니다 |
| 나만의 공략 메모 | 홀마다 메모를 남기면 다음에 그 홀에 왔을 때 공략법과 함께 표시됩니다 |
| 내 클럽 거리 설정 | 클럽별 거리를 입력하면 공략법의 기준이 됩니다. 거리 간격이 겹치거나 비었는지도 점검해 줍니다 |
| 약점 진단 | 기록이 쌓이면 퍼팅·페어웨이·파온·벌타를 기준선과 비교해 개선 우선순위를 알려줍니다 |
| 음성 샷 기록 | 마이크 한 번에 샷 하나씩. 클럽·타구질·거리·결과를 말하면 쌓여서 홀 스코어가 자동 계산됩니다 |
| 타구질 분석 | 정타·뒷땅·뱀샷·슬라이스 비율과 퍼팅 거리 편향을 집계해 원인을 짚어 줍니다 |
| 백업 / 내보내기 | JSON 백업, CSV 내보내기, 구글 시트 동기화(선택) |

## 2. 실행 방법

### 가장 간단한 방법 (PC)

`index.html` 을 더블클릭하면 바로 열립니다. 기록·통계·공략법 전부 동작합니다.

> 단, `file://` 로 열면 **구글 시트 동기화**와 **홈 화면 설치(PWA)** 는 브라우저 정책상 막힙니다.
> 그 두 가지가 필요하면 아래 방법을 쓰세요.

### 로컬 서버로 열기 (권장)

이 폴더에서:

```bash
python -m http.server 8777
```

브라우저에서 `http://localhost:8777` 로 접속합니다.

### 폰에서 쓰기 (필드용)

필드에서 쓰려면 폰에 올려야 합니다. 두 가지 방법이 있습니다.

**(A) 같은 와이파이에서 PC 서버에 접속** — 임시로 써 볼 때

1. PC에서 위 `python -m http.server 8777` 실행
2. PC의 IP 확인 (`ipconfig`)
3. 폰 브라우저에서 `http://<PC의IP>:8777` 접속

**(B) 인터넷에 올리기** — 실제로 필드에서 쓸 때 (권장)

GitHub Pages, Netlify, Vercel 같은 무료 정적 호스팅에 이 폴더를 통째로 올리면 됩니다.
예: GitHub 저장소를 만들어 파일을 올리고 Settings > Pages 에서 브랜치를 지정하면
`https://아이디.github.io/저장소이름/` 주소가 생깁니다.

그 주소를 폰 크롬에서 열고 **메뉴 > 홈 화면에 추가** 를 누르면 앱 아이콘이 생기고,
그 뒤로는 **비행기 모드에서도 열립니다.** (서비스 워커가 파일을 캐시합니다)

기록은 폰 안에 저장되므로 골프장에 신호가 안 잡혀도 문제없습니다.

## 3. 처음 한 번만 할 설정

### (1) 내 클럽 거리 확인

**설정 > 내 클럽 거리** (단위는 야드로 설정돼 있습니다)

기본값에 알려주신 실측 거리가 이미 들어가 있습니다.

| 클럽 | 거리 | 출처 |
|---|---|---|
| 드라이버 | 220y | 실측 |
| 3번 우드 | 200y | 실측 |
| 4번 유틸 | 185y | 실측 |
| 5번 유틸 | 180y | 실측 |
| 5번 아이언 | 170y | 추정 |
| 6번 아이언 | 160y | 추정 |
| 7번 아이언 | **150y** | 실측 |
| 8번 아이언 | 140y | 추정 |
| 9번 아이언 | 128y | 추정 |
| PW / AW / SW / LW | 115 / 100 / 85 / 65y | 추정 |

5번 우드, 3번 유틸, 4번 아이언은 **백에 없는 것으로 보고 0으로 비워 뒀습니다.**
거리 0인 클럽은 공략법 계산에서 빠집니다. 가지고 계시면 거리를 넣으면 바로 반영됩니다.

"추정"으로 표시된 클럽은 실측 4개 사이를 자연스러운 간격으로 채운 값입니다.
연습장에서 재보고 고치면 공략이 더 정확해집니다.

- **캐리(공이 떨어진 지점) 기준**으로 넣으세요. 굴러간 거리까지 넣으면 항상 그린을 넘깁니다.
- **잘 맞았을 때가 아니라, 열 번 중 일곱 번 나오는 거리**를 넣으세요.

> 이미 앱을 쓰고 계셨다면 예전 기본값이 저장돼 있을 수 있습니다.
> **설정 > 내 클럽 거리 > "기본값으로"** 를 누르면 위 표의 값으로 맞춰집니다.

### (2) 동반자 이름

동반자는 **1. 2. 3.** 칸에 한 명씩 따로 넣습니다. 네 명 이상이면 `+ 동반자 추가`를 누르세요.

이름을 한 번 넣으면 그 다음부터는 **자주 치는 분** 칩으로 뜹니다. 눌러서 넣으면 됩니다.
입력칸에서도 여태 쓴 이름이 자동완성으로 나옵니다.

> **같은 사람은 항상 같은 이름으로 넣으세요.** `김철수` 와 `김 철수` 는 다른 사람으로 잡힙니다.
> 앱이 앞뒤 공백과 중복은 정리해 주지만, 표기 자체가 다르면 구분할 방법이 없습니다.
> 자동완성 칩을 쓰는 게 가장 안전합니다.

이렇게 쌓인 이름으로 통계 화면에 **동반자별 평균 스코어 · 베스트 · 라운드 수**가 나옵니다.
(18홀을 마친 라운드만 집계합니다)

### (3) 자주 가는 골프장

**킹스아일랜드(동모) · 스카이레이크 · 피닉스 · 땀다오** 네 곳은 ★ 로 고정해 두어
라운드 시작 화면 맨 위에 바로 나옵니다.

별표를 눌러 다른 골프장을 추가하거나 뺄 수 있습니다.

검색은 별칭으로도 됩니다. `동모` 를 치면 킹스아일랜드가 나옵니다.
(킹스아일랜드는 동모 호수 옆에 있어 한국 골퍼들이 흔히 "동모"라고 부르기 때문에 별칭으로 넣었습니다.
찾으시던 곳이 킹스아일랜드가 아닌 다른 골프장이면 알려주세요.)
별칭은 **골프장 관리 > 골프장 선택 > 별칭** 에서 직접 추가할 수 있습니다.

### (4) 골프장 거리 확인

골프장마다 데이터 신뢰도를 배지로 표시합니다 (스코어카드 / 총거리만 확인 / 거리 추정).
자세한 내용은 아래 "데이터 정확도"를 참고하세요.

배지가 `거리 추정` 인 골프장은 첫 라운드 때 스코어카드를 보고
**설정 > 골프장 관리 > (골프장 선택)** 에서 홀별 파와 블랙티 거리를 채운 뒤
아래쪽 **"실제 값으로 확인함"** 을 누르세요. 배지가 사라지고 공략법이 정확해집니다.

블루/화이트/레드 티는 블랙티 거리에서 자동으로 비율 계산되므로 블랙티 값만 넣으면 됩니다.

### (5) 목표 스코어

**설정 > 목표 스코어** 에 목표 타수를 넣으면(예: 90타), 홀 난이도에 따라
"이 홀 목표: 5타(보기)" 처럼 홀마다 목표를 배분해서 보여 줍니다.

## 4. 라운드 기록하는 법

1. **라운드 탭 > 필드/스크린 선택 > 골프장 선택 > 플레이할 코스 선택 > 티박스 > 시작**
   - 피닉스(챔피언/드래곤/피닉스)처럼 **코스 하나가 18홀**인 골프장은 코스 하나만 고르면 됩니다
   - OUT/IN 으로 나뉜 보통의 18홀 골프장은 **선택하면 두 코스가 자동으로 잡힙니다**
   - 27홀·36홀 골프장(A/B/C…)은 돌 순서대로 두 개를 고르세요
   - 9홀만 도는 라운드도 그대로 기록할 수 있습니다
2. 홀 화면에서:
   - 위쪽에 **공략법**이 나옵니다
   - **사용한 클럽**을 친 순서대로 누릅니다
     - 한 번 = **1회(초록)**, 두 번 = **2회(파랑)**, 세 번 = **해제**
     - 누르는 즉시 스코어가 다시 계산됩니다
   - **퍼팅 수**를 +/- 로 입력합니다
   - 스코어는 `샷 + 퍼팅 + 벌타` 로 **자동 계산**됩니다. 다르면 +/- 로 직접 고치면 되고, 그 뒤로는 수동값이 유지됩니다
   - 티샷 결과(좌/페어웨이/우), 파온, OB/해저드/벙커를 기록합니다
   - **아이언샷**(그린을 노린 샷)을 기록합니다 — 아래 참고
   - **다음 ›** 으로 이동
3. 18홀이 끝나면 **라운드 종료** → 스코어카드가 나옵니다

라운드를 도중에 나가도 홈 화면에 "진행 중"으로 남아 이어서 기록할 수 있습니다.

### 음성으로 기록하기 — 마이크 한 번 = 샷 하나

**한 홀을 한 문장으로 말하는 게 아닙니다.** 칠 때마다 한 샷씩 눌러서 쌓고,
쌓인 샷으로 그 홀의 스코어·퍼팅 수·파온·페어웨이가 **자동 계산**됩니다.

```
1타  "드라이버 정타 페어웨이 250미터"
2타  "남은거리 150 8번 아이언 온그린인데 조금 길었음"
3타  "8미터 퍼팅 짧아서 2미터 남음"
4타  "넣었다"
   → 4타 · 퍼팅 2 · 파온 성공 · 페어웨이 안착
```

패널에 지금까지의 샷이 번호와 함께 쌓이고, 아래에 현재 타수가 실시간으로 보입니다.

**한 번에 두 샷도 됩니다.** `다시 / 그리고 / 또 / 이어서` 로 이으면 나눠서 기록합니다.

```
"8번아이언 뒷땅 다시 8번아이언 오버"  →  2개 샷으로 분리
   2타) 8번 아이언 · 뒷땅
   3타) 8번 아이언 · 길음     ← 클럽을 안 말해도 앞 샷에서 이어받습니다
```

**말할 수 있는 것**

| 항목 | 이렇게 말하면 됩니다 |
|---|---|
| 클럽 | 드라이버, 3번우드, 5번유틸, 8번아이언(팔번/에잇아이언), 피칭, 샌드, 웨지 |
| 타구질 | **정타, 뱀샷(토핑/땅볼), 뒷땅, 생크, 슬라이스, 훅, 밀림, 당김** |
| 떨어진 곳 | 페어웨이, 러프, 벙커, 그린, 프린지, 나무, 카트도로, OB, 해저드 |
| 친 자리 | 러프에서, 벙커에서, 그린주변에서, 경사에서 |
| 거리 | "250미터", "남은거리 150", "8미터 퍼팅", "2미터 남음" |
| 미스 | 짧음, 길었음/오버, 왼쪽, 오른쪽, "거리는 맞았는데 오른쪽으로 빠짐" |
| 홀아웃 | 넣었다, 홀인, 컨시드, OK |

**거리 단위는 말한 그대로 씁니다.** 앱이 야드로 설정돼 있어도 "8미터 퍼팅"이라고 하면 8m 로 기록·표시합니다.

**"퍼팅"이라고 안 해도 됩니다.** 앞 샷이 그린에 올라간 뒤에 클럽 없이 말하면 퍼팅으로 봅니다("넣었다", "1미터 남음").

**티샷은 클럽을 안 말하면 드라이버로 봅니다** (파3 제외). `"우측으로 밀려서 러프"` 만 말해도 됩니다.

기록된 샷은 홀 화면의 **샷 기록** 목록에서 확인하고, 잘못 들어간 건 × 로 지울 수 있습니다.

**이 기록이 통계로 이어집니다**

| 통계 | 무엇을 알 수 있나 |
|---|---|
| **타구질** | 정타 / 뒷땅 / 뱀샷 / 슬라이스 비율. 뒷땅·뱀샷이 25%를 넘으면 셋업 점검을 알려줍니다 |
| **퍼팅 상세** | 첫 퍼트 평균 거리, 치고 나서 남는 평균 거리, 짧음/길음/좌우 편향 |
| **아이언샷** | 남은 거리별 온그린 여부, 페어웨이 vs 러프 적중률 |

퍼팅이 계속 짧으면 "홀을 30~40cm 지나가는 세기로 치세요", 첫 퍼트 후 1.5m 이상 남으면 "1m 안에 붙이면 3퍼트가 사라집니다" 처럼 원인과 처방을 같이 보여 줍니다.

> **⚠ 음성 인식은 인터넷 연결이 필요합니다.**
> 브라우저가 음성을 구글 서버로 보내 글자로 바꾸는 방식이라, **신호가 없는 홀에서는 동작하지 않습니다.**
> 그때는 손으로 입력하시면 됩니다.
>
> **말한 문장은 항상 샷에 원문 그대로 저장됩니다.** 엉뚱하게 알아들어도
> 샷 기록에 원문이 남아 있어 나중에 보고 고칠 수 있습니다.
> 음성 파일 자체는 저장하지 않습니다(저장 공간 문제).
>

### 아이언샷 기록

**+ 아이언샷 기록 추가** 를 누르면 네 가지를 입력합니다. 한 홀에 여러 개 넣을 수 있습니다.

| 항목 | 내용 |
|---|---|
| 남은 거리 | 그린까지 남은 거리 |
| 샷 지점 | 페어웨이 / 러프 / 벙커 |
| 선택한 클럽 | 실제로 잡은 클럽 |
| 결과 | 온그린 / 좌측 미스 / 우측 미스 / 짧음 / 오버 — **2개까지** (예: `짧음 + 좌측 미스`) |

이 기록이 쌓이면 통계 화면에 **아이언샷 분석**이 나옵니다.
짧음이 오버보다 훨씬 많으면 "클럽 거리가 과대 입력됐다"고 알려주고,
페어웨이와 러프의 그린 적중률 차이도 비교해 줍니다. 파온율이 낮은 진짜 원인을 찾는 데 쓰입니다.

## 5. 데이터 정확도에 대한 안내 (꼭 읽어 주세요)

골프장마다 데이터의 신뢰도가 다릅니다. 목록과 골프장 화면에 **배지**로 표시됩니다.

| 배지 | 뜻 |
|---|---|
| **스코어카드** | 공개된 실제 스코어카드 기반. 홀별 파와 난이도 순번이 실제 값 |
| **스코어카드 일부** | 27홀 중 두 코스만 카드가 있고 나머지 한 코스는 추정 |
| **총거리만 확인** | 공식 총 길이만 확인. 홀별 파·거리는 추정 |
| **거리 추정** | 자료를 찾지 못해 표준 규격에서 만들어낸 값 |
| **내가 확인함** | 사용자가 직접 스코어카드를 보고 수정한 코스 |

없는 데이터를 진짜인 것처럼 넣지 않기 위해 이렇게 구분했습니다.
`거리 추정` 이나 `총거리만 확인` 인 골프장은 스코어카드를 보고 5분만 채워 넣으시면
그 다음부터 정확한 공략법이 나옵니다.

핸디캡(홀 난이도 순번)은 스코어카드 값이 있으면 그것을 쓰고,
없으면 선택한 18홀 안에서 파와 거리를 기준으로 자동 계산합니다.

## 7. 구글 시트 동기화 (선택)

앱 → 구글 시트 **한 방향**으로 밀어 넣습니다. 동기화할 때마다 시트 내용을 앱 기록으로 덮어씁니다.
시트에서 직접 고친 값은 다음 동기화 때 사라지니 주의하세요.

`홀기록`, `라운드요약`, `클럽거리` 세 개의 시트가 자동으로 만들어집니다.

### 조건

- 앱이 **https 주소**에서 열려 있어야 합니다 (`file://` 에서는 구글 로그인이 막힙니다)
- 구글 클라우드 콘솔에서 OAuth 클라이언트 ID를 직접 발급받아야 합니다

### 설정 순서

1. [console.cloud.google.com](https://console.cloud.google.com) 에서 프로젝트 생성
2. **API 및 서비스 > 라이브러리** 에서 `Google Sheets API` 사용 설정
3. **OAuth 동의 화면** 구성 (외부 / 테스트 모드), 테스트 사용자에 본인 구글 계정 추가
4. **사용자 인증 정보 > OAuth 클라이언트 ID > 웹 애플리케이션** 생성
   - "승인된 자바스크립트 원본"에 앱 주소를 입력 (예: `https://아이디.github.io`)
5. 발급된 클라이언트 ID를 앱의 **설정 > 구글 시트 동기화** 에 붙여넣기
6. 구글 드라이브에서 빈 스프레드시트를 하나 만들고, 주소를 그대로 붙여넣기
7. **지금 동기화** 클릭

```
index.html                 화면 뼈대 + 스크립트 로드 순서
manifest.webmanifest       홈 화면 설치용 정보
sw.js                      오프라인 캐시 (파일 수정 시 CACHE 이름의 버전을 올릴 것)
icon.svg                   앱 아이콘
css/style.css              전체 스타일 (모바일 우선, 다크)
js/util.js                 DOM 헬퍼, 단위 변환, 스코어 명칭, 토스트
js/courses.js              골프장 기본 데이터 + 티박스 정의
js/store.js                localStorage 저장소, 라운드 생성, 집계, 백업

js/app.js                  해시 라우터, 하단 탭, 홈 화면
js/view-round.js           새 라운드 / 홀 기록 / 스코어카드
```

빌드 도구·의존성이 없습니다. 파일을 고치고 새로고침하면 끝입니다.
(서비스 워커를 등록한 상태라면 `sw.js` 의 `CACHE` 버전을 올려야 반영됩니다)
