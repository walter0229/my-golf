# 골프 스코어 관리

필드와 스크린골프를 따로 관리하고, 홀마다 사용한 클럽과 퍼팅 수를 기록하며,
내 클럽 거리를 기준으로 홀별 공략법을 계산해 주는 오프라인 웹앱(PWA)입니다.

설치 프로그램도, 서버도, 로그인도 필요 없습니다. 브라우저만 있으면 됩니다.

---

## 1. 무엇을 할 수 있나

| 기능 | 설명 |
|---|---|
| 필드 / 스크린 분리 | 라운드마다 구분해서 저장하고, 통계도 따로 볼 수 있습니다 |
| 골프장 · 코스 선택 | 베트남 필드 골프장 49곳 + 스크린 코스 템플릿 11개가 기본 내장. 골프장마다 9홀 코스(OUT/IN, A/B/C…)를 골라 18홀을 구성합니다 |
| 홀별 클럽 기록 | 사용한 클럽을 순서대로 눌러 기록. 티샷 클럽별 성적이 통계로 나옵니다 |
| 퍼팅 별도 관리 | 홀마다 퍼팅 수를 따로 기록해 라운드당 퍼팅 수, 3퍼트·1퍼트 횟수를 집계합니다 |
| 홀별 공략법 | 홀 거리와 내 클럽 거리를 비교해 "드라이버 → 남은 130m는 7번 아이언" 식으로 루트를 계산. 파5는 레이업 지점까지 잡아 줍니다 |
| 나만의 공략 메모 | 홀마다 메모를 남기면 다음에 그 홀에 왔을 때 공략법과 함께 표시됩니다 |
| 내 클럽 거리 설정 | 클럽별 거리를 입력하면 공략법의 기준이 됩니다. 거리 간격이 겹치거나 비었는지도 점검해 줍니다 |
| 약점 진단 | 기록이 쌓이면 퍼팅·페어웨이·파온·벌타를 기준선과 비교해 개선 우선순위를 알려줍니다 |
| 백업 / 내보내기 | JSON 백업, CSV 내보내기, 구글 시트 동기화(선택) |

## 2. 실행 방법

### 가장 간단한 방법 (PC)

`index.html` 을 더블클릭하면 바로 열립니다. 기록·통계·공략법 전부 동작합니다.

> 단, `file://` 로 열면 **구글 시트 동기화**와 **홈 화면 설치(PWA)** 는 브라우저 정책상 막힙니다.
> 그 두 가지가 필요하면 아래 방법을 쓰세요.

### 로컬 서버로 열기 (권장)

이 폴더에서:

```bash
python -m http.server 8777
```

브라우저에서 `http://localhost:8777` 로 접속합니다.

### 폰에서 쓰기 (필드용)

필드에서 쓰려면 폰에 올려야 합니다. 두 가지 방법이 있습니다.

**(A) 같은 와이파이에서 PC 서버에 접속** — 임시로 써 볼 때

1. PC에서 위 `python -m http.server 8777` 실행
2. PC의 IP 확인 (`ipconfig`)
3. 폰 브라우저에서 `http://<PC의IP>:8777` 접속

**(B) 인터넷에 올리기** — 실제로 필드에서 쓸 때 (권장)

GitHub Pages, Netlify, Vercel 같은 무료 정적 호스팅에 이 폴더를 통째로 올리면 됩니다.
예: GitHub 저장소를 만들어 파일을 올리고 Settings > Pages 에서 브랜치를 지정하면
`https://아이디.github.io/저장소이름/` 주소가 생깁니다.

그 주소를 폰 크롬에서 열고 **메뉴 > 홈 화면에 추가** 를 누르면 앱 아이콘이 생기고,
그 뒤로는 **비행기 모드에서도 열립니다.** (서비스 워커가 파일을 캐시합니다)

기록은 폰 안에 저장되므로 골프장에 신호가 안 잡혀도 문제없습니다.

## 3. 처음 한 번만 할 설정

### (1) 내 클럽 거리 확인

**설정 > 내 클럽 거리** (단위는 야드로 설정돼 있습니다)

기본값에 알려주신 실측 거리가 이미 들어가 있습니다.

| 클럽 | 거리 | 출처 |
|---|---|---|
| 드라이버 | 220y | 실측 |
| 3번 우드 | 200y | 실측 |
| 4번 유틸 | 185y | 실측 |
| 5번 유틸 | 180y | 실측 |
| 5번 아이언 | 170y | 추정 |
| 6번 아이언 | 160y | 추정 |
| 7번 아이언 | **150y** | 실측 |
| 8번 아이언 | 140y | 추정 |
| 9번 아이언 | 128y | 추정 |
| PW / AW / SW / LW | 115 / 100 / 85 / 65y | 추정 |

5번 우드, 3번 유틸, 4번 아이언은 **백에 없는 것으로 보고 0으로 비워 뒀습니다.**
거리 0인 클럽은 공략법 계산에서 빠집니다. 가지고 계시면 거리를 넣으면 바로 반영됩니다.

"추정"으로 표시된 클럽은 실측 4개 사이를 자연스러운 간격으로 채운 값입니다.
연습장에서 재보고 고치면 공략이 더 정확해집니다.

- **캐리(공이 떨어진 지점) 기준**으로 넣으세요. 굴러간 거리까지 넣으면 항상 그린을 넘깁니다.
- **잘 맞았을 때가 아니라, 열 번 중 일곱 번 나오는 거리**를 넣으세요.

> 이미 앱을 쓰고 계셨다면 예전 기본값이 저장돼 있을 수 있습니다.
> **설정 > 내 클럽 거리 > "기본값으로"** 를 누르면 위 표의 값으로 맞춰집니다.

### (2) 자주 가는 골프장

**킹스아일랜드(동모) · 스카이레이크 · 피닉스 · 땀다오** 네 곳은 ★ 로 고정해 두어
라운드 시작 화면 맨 위에 바로 나옵니다.

별표를 눌러 다른 골프장을 추가하거나 뺄 수 있습니다.

검색은 별칭으로도 됩니다. `동모` 를 치면 킹스아일랜드가 나옵니다.
(킹스아일랜드는 동모 호수 옆에 있어 한국 골퍼들이 흔히 "동모"라고 부르기 때문에 별칭으로 넣었습니다.
찾으시던 곳이 킹스아일랜드가 아닌 다른 골프장이면 알려주세요.)
별칭은 **골프장 관리 > 골프장 선택 > 별칭** 에서 직접 추가할 수 있습니다.

### (3) 골프장 거리 확인

기본 내장된 골프장에는 **`거리 미확인`** 배지가 붙어 있습니다. 이유는 아래 "데이터 정확도"를 참고하세요.

자주 가는 골프장은 첫 라운드 때 스코어카드를 보고
**설정 > 골프장 관리 > (골프장 선택)** 에서 홀별 파와 블랙티 거리를 채운 뒤
아래쪽 **"실제 값으로 확인함"** 을 누르세요. 배지가 사라지고 공략법이 정확해집니다.

블루/화이트/레드 티는 블랙티 거리에서 자동으로 비율 계산되므로 블랙티 값만 넣으면 됩니다.

### (4) 목표 스코어

**설정 > 목표 스코어** 에 목표 타수를 넣으면(예: 90타), 홀 난이도에 따라
"이 홀 목표: 5타(보기)" 처럼 홀마다 목표를 배분해서 보여 줍니다.

## 4. 라운드 기록하는 법

1. **라운드 탭 > 필드/스크린 선택 > 골프장 선택 > 코스 2개 선택(앞 9홀, 뒤 9홀) > 티박스 > 시작**
2. 홀 화면에서:
   - 위쪽에 **공략법**이 나옵니다
   - **사용한 클럽**을 친 순서대로 누릅니다 (칩을 누르면 취소)
   - **퍼팅 수**를 +/- 로 입력합니다
   - 스코어는 `샷 + 퍼팅 + 벌타` 로 **자동 계산**됩니다. 다르면 +/- 로 직접 고치면 되고, 그 뒤로는 수동값이 유지됩니다
   - 티샷 결과(좌/페어웨이/우), 파온, OB/해저드/벙커를 기록합니다
   - **다음 ›** 으로 이동
3. 18홀이 끝나면 **라운드 종료** → 스코어카드가 나옵니다

라운드를 도중에 나가도 홈 화면에 "진행 중"으로 남아 이어서 기록할 수 있습니다.

## 5. 데이터 정확도에 대한 안내 (꼭 읽어 주세요)

기본 내장된 베트남 골프장은 **이름 · 지역 · 코스(9홀) 구성**까지는 알려진 정보를 바탕으로 넣었습니다.

하지만 **홀별 파 배치, 거리, 핸디캡 순번은 실제 스코어카드 값이 아닙니다.**
파 72 표준 규격에서 만들어낸 추정값입니다. 실제와 다릅니다.

이 코스들에는 앱 안에서 `거리 미확인` 배지가 붙어 있고, 공략법 아래에도
"이 코스의 거리는 추정값입니다"라는 안내가 뜹니다.

없는 데이터를 진짜인 것처럼 넣지 않기 위해 이렇게 만들었습니다.
자주 가는 골프장부터 스코어카드를 보고 5분만 투자해 채워 넣으시면
그 다음부터는 정확한 공략법이 나옵니다.

핸디캡(홀 난이도 순번)은 저장하지 않고, 선택한 18홀 안에서
파와 거리를 기준으로 매번 자동 계산합니다.

### 내장된 골프장

- **북부(하노이·하이퐁·닌빈·꽝닌)**: 킹스아일랜드, 레전드힐, 반찌, 롱비엔, 스카이레이크, 피닉스, 힐탑밸리, 땀다오, 다이라이, 헤론레이크, 타인란, 찌린, 루비트리, 빈펄 하이퐁, 옌중, 짱안, 로얄 닌빈, FLC 하롱베이
- **중부(타인호아~다낭·호이안·냐짱·달랏·판티엣)**: FLC 삼손, 끄어로, 지엔럼, 쑤언타인, FLC 꽝빈, 라구나 랑꼬, BRG 다낭(노먼/레전드), 바나힐스, 몽고메리, 호이아나 쇼어스, 빈펄 남호이안, 빈펄 냐짱, KN 깜라인, 다이아몬드베이, 달랏 팰리스, SAM 뚜옌럼, 달랏 1200, PGA 오션, 씨링크스
- **남부(호치민·빈즈엉·동나이·붕따우·푸꾸옥)**: 베트남 GCC, 떤선녓, 송베, 트윈도브스, 하모니, 메콩, 롱타인, 태광 정산, 동나이, 더 블러프스 호짬, 빈펄 푸꾸옥

목록에 없으면 **골프장 관리 > + 골프장 추가** 로 직접 만들면 됩니다.

## 6. 백업

기록은 **이 브라우저 안에만** 저장됩니다. 브라우저 데이터를 지우거나 앱을 삭제하면 사라집니다.
가끔 **설정 > 백업 파일 저장** 으로 JSON 파일을 받아 두세요. 복원도 같은 화면에서 됩니다.

**CSV로 내보내기** 를 쓰면 홀 단위 데이터가 엑셀·구글 시트에서 바로 열립니다.
구글 시트 연동 설정이 번거로우면 이 방법이 가장 간단합니다.

## 7. 구글 시트 동기화 (선택)

앱 → 구글 시트 **한 방향**으로 밀어 넣습니다. 동기화할 때마다 시트 내용을 앱 기록으로 덮어씁니다.
시트에서 직접 고친 값은 다음 동기화 때 사라지니 주의하세요.

`홀기록`, `라운드요약`, `클럽거리` 세 개의 시트가 자동으로 만들어집니다.

### 조건

- 앱이 **https 주소**에서 열려 있어야 합니다 (`file://` 에서는 구글 로그인이 막힙니다)
- 구글 클라우드 콘솔에서 OAuth 클라이언트 ID를 직접 발급받아야 합니다

### 설정 순서

1. [console.cloud.google.com](https://console.cloud.google.com) 에서 프로젝트 생성
2. **API 및 서비스 > 라이브러리** 에서 `Google Sheets API` 사용 설정
3. **OAuth 동의 화면** 구성 (외부 / 테스트 모드), 테스트 사용자에 본인 구글 계정 추가
4. **사용자 인증 정보 > OAuth 클라이언트 ID > 웹 애플리케이션** 생성
   - "승인된 자바스크립트 원본"에 앱 주소를 입력 (예: `https://아이디.github.io`)
5. 발급된 클라이언트 ID를 앱의 **설정 > 구글 시트 동기화** 에 붙여넣기
6. 구글 드라이브에서 빈 스프레드시트를 하나 만들고, 주소를 그대로 붙여넣기
7. **지금 동기화** 클릭

## 8. 파일 구성

```
index.html                 화면 뼈대 + 스크립트 로드 순서
manifest.webmanifest       홈 화면 설치용 정보
sw.js                      오프라인 캐시 (파일 수정 시 CACHE 이름의 버전을 올릴 것)
icon.svg                   앱 아이콘
css/style.css              전체 스타일 (모바일 우선, 다크)
js/util.js                 DOM 헬퍼, 단위 변환, 스코어 명칭, 토스트
js/courses.js              골프장 기본 데이터 + 티박스 정의
js/store.js                localStorage 저장소, 라운드 생성, 집계, 백업
js/strategy.js             홀 공략법 계산 (클럽 선택, 레이업, 목표 타수 배분)
js/stats.js                통계 집계 + 약점 진단
js/app.js                  해시 라우터, 하단 탭, 홈 화면
js/view-round.js           새 라운드 / 홀 기록 / 스코어카드
js/view-stats.js           통계 화면
js/view-settings.js        설정 / 클럽 / 골프장 관리
js/sheets.js               구글 시트 동기화
```

거리는 내부적으로 **항상 미터**로 저장하고, 화면에 보일 때만 야드로 변환합니다.
설정에서 단위를 바꿔도 저장된 값은 그대로입니다.

빌드 도구·의존성이 없습니다. 파일을 고치고 새로고침하면 끝입니다.
(서비스 워커를 등록한 상태라면 `sw.js` 의 `CACHE` 버전을 올려야 반영됩니다)
